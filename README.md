# Buddy website

Public static website for https://meetbuddy.me.

Source: https://github.com/ilinii/buddy, AGPL-3.0-only.

Built from source commit 501c89d using `npm ci` and `npm run website:build`. Only generated public website files belong here. Keep CNAME and .nojekyll.

The browser demo uses local storage and clearly marked sample meetings. This deployment has no live cloud voice gateway or provider credentials. Native transcription is configured separately in Buddy.
